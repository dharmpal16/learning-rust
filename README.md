# Rust

# Running first program of the Rust

1. create `main.rs` file
2. Write this test code in `main.rs` file
   ```rs
   fn main() {
       println!("Hello, Word!");
   }
   ```
3. Run this command to compile the code.\
   This command create a compiled file of the code
   ```sh
   rustc main.rs
   ```
4. Run the compile code
   ```sh
   ./main
   ```
5. Final output of this code.
   ```bash
   Hello, Word!
   ```
   
---

* version control tool in rust is `rustup`

* for update use
  ```sh
  rustup update
  
  ```
* for uninstall
  ```sh
  rustup self uninstall
  ```
